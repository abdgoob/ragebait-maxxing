build is cmake, need sfml 2.5 ish (course sfml)

mac if cmake not found: brew install cmake sfml@2
then from repo:
export PATH="/opt/homebrew/bin:$PATH"
mkdir build && cd build
CMAKE_PREFIX_PATH=/opt/homebrew/opt/sfml@2 cmake ..
cmake --build .
./ragebait_maxxing

windows (native, not wsl if you already have sfml from lab or installer)
install cmake from cmake.org installer and sfml 2.6 windows 64bit binaries from sfml-dev.org download page, pick visual studio version that matches what you use
put sfml somewhere simple like C:\SFML and set env var SFML_DIR to C:\SFML (folder that has include and lib)
open x64 native tools command prompt for vs or regular cmd if mingw make sure compiler matches sfml libs
cd path\to\ragebait-maxxing
mkdir build
cd build
cmake .. -DCMAKE_PREFIX_PATH=C:/SFML
cmake --build . --config Release
run build\Release\ragebait_maxxing.exe (or ragebait_maxxing.exe in build if single config)
if cmake cant find sfml pass -DSFML_DIR=C:/SFML/lib/cmake/SFML or whatever path the sfml zip has

wsl/linux use your lab sfml setup, same mkdir build cmake .. cmake --build . then ./ragebait_maxxing
